# AmirHossein Norbakhsh — Personal Portfolio

Personal portfolio website for AmirHossein Norbakhsh, a Frontend Engineer focused on React, Next.js, TypeScript, UI engineering, and web performance.

## Live Portfolio

[amirnbk.netlify.app](https://amirnbk.netlify.app/)

## Overview

The portfolio presents selected professional work, frontend projects, experience, technical skills, and contact information in a recruiter-friendly format.

## Focus Areas

- React, Next.js and TypeScript
- Scalable and maintainable frontend architecture
- Responsive and accessible UI implementation
- Web performance and Core Web Vitals
- UI/UX and design-to-code implementation
- Testing, Storybook, CI/CD and production workflows

## Structure

This is a lightweight static portfolio built with HTML, CSS, Bootstrap, JavaScript and supporting frontend plugins. The original visual identity is retained while the content and information architecture are maintained around current frontend engineering experience.

## Run Locally

Open `index.html` in a local web server, or serve the directory with any static-file development server.
