# AmirHossein Norbakhsh — Personal Portfolio

Personal portfolio website for AmirHossein Norbakhsh, a frontend engineer focused on React, Next.js, TypeScript, UI engineering, and web performance.

## Overview

The portfolio presents selected frontend work, professional experience, and technical interests in a concise format for recruiters, hiring managers, and engineering teams.

## Focus Areas

- React and Next.js development
- TypeScript and maintainable frontend architecture
- Responsive, accessible UI implementation
- Web performance and Core Web Vitals
- UI/UX and design-to-code implementation
- AI-assisted development with human validation

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server using the project's configured npm script:

```bash
npm run dev
```
